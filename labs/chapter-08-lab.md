# Chapter 8 Lab: Cloud Technology and Services: Storage and Database Services

**Estimated time:** 20 minutes

## Exercise

Create an S3 bucket in a free-tier account, upload a sample file, then change its storage class to S3 Glacier Instant Retrieval and observe the pricing/retrieval implications shown in the console

## Key takeaway

Storage and database questions test whether you can map a workload's access pattern (block, file, object, relational, NoSQL, analytical) to the single correct AWS service.
