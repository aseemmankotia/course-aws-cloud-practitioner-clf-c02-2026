# Chapter 11 Lab: Billing, Pricing, and Support: Cost Management Tools and Support Plans

**Estimated time:** 15 minutes

## Exercise

In a free-tier account, open Cost Explorer to view sample cost data, then create an AWS Budget with a $1 monthly threshold and set up an email alert

## Key takeaway

Billing tool questions test whether you know each tool's single job — visualize (Cost Explorer), alert (Budgets), estimate (Pricing Calculator), or detailed export (Cost and Usage Report).
