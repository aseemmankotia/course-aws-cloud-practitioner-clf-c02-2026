# Chapter 7 Lab: Cloud Technology and Services: Compute Services

**Estimated time:** 25 minutes

## Exercise

Launch a free-tier t2.micro or t3.micro EC2 instance via the Management Console, then create and manually invoke a simple 'Hello World' AWS Lambda function to compare the operational effort of each

## Key takeaway

Compute questions test matching a workload pattern (steady, unpredictable, containerized) to the right service — EC2, Lambda, ECS, EKS, or Elastic Beanstalk.
