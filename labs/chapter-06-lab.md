# Chapter 6 Lab: Cloud Technology and Services: Global Infrastructure and Deployment Methods

**Estimated time:** 20 minutes

## Exercise

Install and configure the AWS CLI on a free-tier account, run 'aws configure' with sample credentials, then run 'aws sts get-caller-identity' to confirm connectivity

## Key takeaway

The exam frequently tests whether you can correctly place Regions, AZs, and edge locations in the right hierarchy and match deployment methods to scenarios.
