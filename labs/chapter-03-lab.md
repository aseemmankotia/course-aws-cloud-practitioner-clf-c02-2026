# Chapter 3 Lab: Security and Compliance: The Shared Responsibility Model

**Estimated time:** 10 minutes

## Exercise

Review the AWS Shared Responsibility Model diagram from AWS documentation and complete a responsibility-mapping worksheet comparing EC2, RDS, and Lambda across categories like OS patching, network controls, and data encryption

## Key takeaway

Every shared responsibility question tests whether you know the split shifts more toward AWS as you move from EC2 toward managed and serverless services.
