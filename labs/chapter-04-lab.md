# Chapter 4 Lab: Security and Compliance: Identity and Access Management (IAM)

**Estimated time:** 20 minutes

## Exercise

In a free-tier AWS account, create a new IAM user, enable virtual MFA on it, attach an AWS managed policy granting read-only S3 access, and verify the permissions using the IAM policy simulator

## Key takeaway

IAM questions test the precise difference between users, groups, roles, and policies — know which one provides temporary credentials and which one groups permissions.
