# Chapter 1 Lab: Cloud Concepts: The AWS Cloud Value Proposition

**Estimated time:** 15 minutes

## Exercise

Log into the AWS Management Console (free tier), open the Region selector to view available Regions, and browse the AWS Well-Architected Tool landing page to see how AWS frames cloud value at a high level

## Key takeaway

The exam tests whether you can match a business scenario to the correct cloud advantage (agility, elasticity, global reach, cost) rather than memorized definitions.
