# Chapter 9 Lab: Cloud Technology and Services: Networking and AI/ML Awareness

**Estimated time:** 20 minutes

## Exercise

Use the VPC Wizard in a free-tier account to create a simple custom VPC with one public subnet, then review the default Security Group and Network ACL rules attached

## Key takeaway
