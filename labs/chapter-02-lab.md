# Chapter 2 Lab: Cloud Concepts: Cloud Economics and the Well-Architected Framework

**Estimated time:** 15 minutes

## Exercise

Use the AWS Pricing Calculator to build a sample cost estimate for a small EC2-based workload, then open the AWS Well-Architected Tool and review the list of pillars in a sample workload review

## Key takeaway

Cloud economics questions test your ability to identify whether a scenario describes CapEx vs OpEx, TCO reduction, or a specific Well-Architected pillar.
