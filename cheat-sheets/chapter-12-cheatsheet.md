# Chapter 12 Cheat Sheet: Exam Simulation & Test-Taking Strategy

## Exam Format Numbers
| Item | Value |
|---|---|
| Total questions | 65 |
| Total time | 90 minutes |
| Unscored questions | 15 (randomly mixed, unidentifiable) |
| Scaled score range | 100–1000 |
| Passing score | 700 |
| Penalty for wrong answers | None — always answer |

## Pacing Plan
| Phase | Time | Action |
|---|---|---|
| First pass | 0–80 min | Answer all 65; flag uncertain ones with best guess |
| Buffer/review | Last 10 min | Revisit ONLY flagged questions |
| Target pace | ~1.2 min/question | Recheck pace every ~15 questions |

**Checkpoint rule:** By 30 min ≈ 25 questions done. By 60 min ≈ 50 questions done. If behind, speed up on flags — don't slow down on new questions.

## Flag-and-Review Workflow
1. Read question, eliminate obviously wrong options.
2. If unsure between 2 options → pick best guess, hit **Flag**, move on.
3. Never leave a question blank — no guessing penalty.
4. Use final minutes to revisit flagged items only.

## Process of Elimination Checklist
- Does the option ignore a stated constraint (cost, compliance, latency, scale)? → Eliminate.
- Is the service deprecated or clearly mismatched to the use case? → Eliminate.
- Is the option technically true but NOT the *best* fit for the scenario? → Eliminate.
- Remaining option = answer.

## Test Delivery Options
| Option | Environment | Requirements |
|---|---|---|
| Pearson VUE test center | Staffed physical site | Valid ID, arrive early |
| Pearson OnVUE (online) | Home/private room | Webcam room scan, ID check, no other people/devices nearby |

## Common Traps
- Treating all 65 questions as equally weighted in visible feedback — they are NOT distinguishable as scored/unscored, so treat every question seriously.
- Overspending time on early questions, leaving no time for the back half of the exam.
- Selecting a technically correct but constraint-ignoring answer over the scenario-optimal one.
- Forgetting flagged questions still need a submitted answer, not just a flag.

## Final-Minutes Priority
1. Flagged questions with genuine uncertainty.
2. Any question left literally blank (should be rare if pacing followed).
3. Do NOT reopen and second-guess confidently answered questions — this wastes time and often lowers accuracy.
